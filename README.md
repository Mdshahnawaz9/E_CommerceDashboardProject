# 🛒 E-Commerce Sales, Customer & Product Analytics

##  Project Overview
This project focuses on analyzing e-commerce sales, customer behavior, product performance, order status, and payment trends using **Microsoft Power BI**. The goal is to transform raw data into meaningful business insights through interactive dashboards and visualizations.

##  Project Objectives
- Analyze overall sales and revenue performance.
- Understand customer behavior and repeat purchasing patterns.
- Identify top-performing products and product categories.
- Monitor order delivery, cancellations, and payment methods.
- Analyze customer value and retention.
- Support data-driven business decisions using interactive dashboards.

##  Tools & Technologies
- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures, KPIs, and calculations
- **CSV Files** – Dataset storage
- **Microsoft Word** – Project documentation

##  Dataset Description

The project uses four datasets:

| Dataset | Description |
|---|---|
| Customers | Customer details and signup information |
| Products | Product names, categories, prices, and stock |
| Orders | Order dates, customer IDs, payment methods, and statuses |
| Order Items | Products included in orders, quantities, and unit prices |

##  Data Cleaning & Preparation
The following steps were performed using Power Query:

- Checked and assigned appropriate data types.
- Cleaned text fields using Trim and Clean.
- Checked duplicate records and primary keys.
- Validated relationships between related tables.
- Checked foreign key references for data consistency.
- Created an order value column using quantity and unit price.
- Categorized products according to their stock status.

##  Data Modeling
The data model connects the four datasets using their relevant IDs.

- Customers → Orders
- Orders → Order Items
- Products → Order Items
- Date Table → Orders

A separate Date Table was created to support date-based analysis.

##  Power BI Dashboards

### 1. Sales Performance Dashboard
Analyzes total revenue, total orders, average order value, quantity sold, revenue trends, category performance, and order status distribution.

### 2. Customer Analytics Dashboard
Analyzes total customers, new customers, repeat customers, customer signup trends, customer distribution by city, and revenue generated by individual customers.

### 3. Product & Category Analytics Dashboard
Evaluates product performance, category revenue, quantity sold, stock status distribution, top-performing products, and lower-revenue products.

### 4. Orders & Payments Analytics Dashboard
Analyzes order statuses, delivery rate, cancellation rate, payment methods, revenue by payment method, and monthly order trends.

### 5. Customer Value & Retention Dashboard
Examines repeat customer behavior, customer segmentation, customer purchase frequency, revenue by customer segment, and high-value customers.

### 6. Executive Summary Dashboard
Provides a consolidated overview of key business KPIs, revenue trends, product category performance, customer value, payment methods, and order statuses.

##  Key Performance Indicators (KPIs)

- Total Revenue
- Total Orders
- Average Order Value (AOV)
- Total Quantity Sold
- Total Customers
- New Customers
- Repeat Customers
- Repeat Customer Rate
- Revenue per Customer
- Total Products
- Total Categories
- Delivered Orders
- Cancelled Orders
- Cancellation Rate
- Delivery Rate

##  Key Business Insights

- Electronics generates the highest revenue among the product categories.
- Repeat customers account for approximately 95% of customers in the current analysis.
- Net Banking records the highest order count among the payment methods.
- The overall cancellation rate is approximately 10.6%.
- Customer and product dashboards help identify valuable customers and top-performing products.

*These insights reflect the dashboard results and may change when report filters are applied.*

##  How to Use This Project

1. Download or clone this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. If required, update the dataset file paths in Power Query.
4. Refresh the data.
5. Explore the dashboards using slicers and interactive visuals.
